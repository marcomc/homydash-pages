Sobre este site

Este site estático não contém análise de visitas, rastreadores, formulários, cookies ou armazenamento no navegador. Não carrega tipos de letra nem scripts de terceiros. O site está alojado no GitHub Pages. O GitHub regista os endereços IP dos visitantes por segurança. Os fornecedores de rede também podem tratar dados de ligação. Os tratamentos da aplicação continuam sujeitos ao aviso separado em preparação.
